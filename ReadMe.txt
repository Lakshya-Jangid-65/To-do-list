# To-Do List Web Application

This is a simple web-based To-Do List application that allows users to add and manage tasks effectively. It is built with HTML, CSS, and JavaScript, featuring a clean and responsive user interface.

## Features

- **Add Tasks:** Users can input new tasks via the input field and add them to the list by clicking the "Add" button or pressing the Enter key.
- **Delete Tasks:** Each task in the list has a delete button to remove it from the list.
- **Responsive Design:** The interface is responsive and works well on various screen sizes.

## Project Structure

- **HTML (`index.html`):**
  Defines the structure of the web page, including the input field, buttons, and task list.

- **CSS (`output.css`):**
  Provides styling for the application, ensuring a visually appealing and user-friendly design.

- **JavaScript (`tdl.js`):**
  Contains the logic for adding and removing tasks, as well as handling user interactions.

## How to Use

1. Open the `index.html` file in a web browser.
2. Enter a task in the input field labeled "Add your Task."
3. Click the "Add" button or press Enter to add the task to the list.
4. To remove a task, click the "Delete" button next to it.

## Technologies Used

- **HTML5**
- **CSS3** (with Google Fonts for typography)
- **JavaScript (ES6)**

## File Descriptions

### `index.html`
The main HTML file, which includes the structure for:
- A side section displaying a header and an image of a coconut tree.
- A main section where the To-Do List functionality resides.

### `output.css`
Handles the application’s styling, including colors, fonts, and layout. Notable styles include:
- `bg-pink-300` and `bg-[#FFEBD4]` for background colors.
- Use of Google Font **Major Mono Display** for unique typography.

### `tdl.js`
The core JavaScript file:
- Adds event listeners for the "Add" button and the Enter key.
- Implements task addition and deletion functionality dynamically.

## Setup

1. Clone the repository or download the files.
2. Make sure all files (`index.html`, `output.css`, `tdl.js`) are in the same directory.
3. Open `index.html` in a web browser to start using the application.
